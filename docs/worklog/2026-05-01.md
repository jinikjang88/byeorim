## 배운 점

- 시드 카탈로그 결정 로직을 어댑터에 두려 하다가 의존성 방향(섹션 3 ai → core)에 막혔다. ai 패키지가 templates에 의존할 수 없어서 default seed 결정을 cli 레이어로 옮겼다. mock generateCatalog는 seedCatalog가 null이면 한국어 에러로 안내한다. cli가 항상 seedCatalog를 채워준다는 약속이 자리 한 줄로 박혔다. 의존성 방향이 또 한 번 자기 결을 지켜준 자리.
- INTENT_SYSTEM_PROMPT의 후보 목록을 동적으로 받으려면 createClaudeAdapter → selectAdapter → bin까지 templateNames pass-through가 필요했다. ai 패키지가 templates를 import할 수 없으니 자연스럽게 호출 자리에서 끌어와야 한다. 작은 수정이 세 자리를 동시에 건드린 자리.
- mock generateTradeOffDoc은 데이터 무관성(섹션 8)을 지키려고 시드의 도메인 ID를 본문에 박지 않고 구조 카운트로만 트레이드오프를 표현했다. "1개 자리가 함께 따라옵니다", "다른 1개 자리의 동작 방식이 바뀝니다" 같은 결. 두 다른 도메인이 같은 구조를 가지면 같은 헤딩 트리가 나오는지 단위 테스트로 못박았다.
- intent.source 매트릭스(template / ai-generated:hybrid / fallback:template)를 ADR로 박는 자리에서 cli-set.test.js의 정규식 한 자리가 같이 깨졌다. source 값 형식 변경은 다운스트림(set의 합성 README)도 같이 본다는 신호. 미래에 source 값 형식을 또 갱신할 때 이 자리도 같이 점검해야 한다.
- 첫 번째 npm test 실행이 dependency 미설치로 23개 fail이 떴다. npm install 한 번 돌리니 정상화. 새 PR 시작할 때 의존성 상태부터 점검하는 게 첫 자리.
